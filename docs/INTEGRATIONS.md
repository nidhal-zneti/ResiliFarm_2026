## Pretrained Studio model (2026-11-21)

The optional Studio provider is now integrated with **Qwen3 4B Instruct**, served by a workspace-local **Ollama 0.40.17** runtime on `127.0.0.1:11434`. The Windows archive was downloaded from the official Ollama GitHub release and verified against its published SHA-256 (`3dd80f6e3a9699f2eadf4ac418f00529cee594df9557541806eda1f1f3f5588a`). Model weights are downloaded by Ollama and checked by its manifest/digest verification, under `.local/models`; they are not committed to source control.

[Qwen3 4B Instruct](https://ollama.com/library/qwen3:4b-instruct) is pretrained and distributed under Apache-2.0. Preserve its license/notices when redistributing weights. [Ollama](https://github.com/ollama/ollama) is the runtime; retain its applicable distribution and third-party notices. The integration sends the original Studio request, typed current options and planning preferences to the configured model. With the supplied launcher this stays on localhost and requires no paid API. A separately configured remote provider would receive those inputs.

AI selects a validated set of catalogue options through JSON-schema output. It does not generate executable firmware, arbitrary components or reviewed wiring. Local code still constructs parts/connections and performs compatibility checks. Failed or malformed AI output produces an explicit error without persistence, not a silent rule fallback. It is not a trained agricultural prediction or anomaly-detection model. Water, energy, stress and telemetry workflows continue to use their documented formulas/rules.

Real-model verification passed EN/FR/JA solar-without-Wi-Fi planning, one-sensor contextual edits, solar removal with LoRa preserved, unsupported requests without persistence and Japanese ZIP export. On this RTX 3060 Laptop GPU (6 GB), the first EN request took 10.19 seconds; subsequent FR/JA creation took 3.99/3.56 seconds. These are local smoke-test timings, not accuracy or performance guarantees. See README and `scripts/verify_studio_ai.py` to reproduce. The earlier repository evaluation above remains historical; no weights from those ten candidate repositories were imported.

## Library attribution

Runtime libraries are installed through package managers, not copied source trees. React/Vite/i18next/Recharts and most UI tooling use MIT; Leaflet is BSD-2-Clause; Lucide uses ISC. FastAPI/Pydantic/SQLAlchemy/HTTPX use MIT; Uvicorn uses BSD-3-Clause; Psycopg uses LGPL-3.0 (retain installed distribution notices). PostgreSQL has the PostgreSQL license. Preserve package license files when redistributing containers/bundles. Google Fonts are optional font requests with system-font fallback; no downloaded font files are bundled.

## Verification limits

No WNTR, pvlib, DiTEC-trained model, NASA/FAO portal or proprietary engineering API is integrated. The simplified implementations are deliberately independent and their assumptions appear in the UI and README. No benchmark accuracy or real-world cybersecurity protection is claimed. PostgreSQL DDL compiles, but Docker/PostgreSQL execution was unavailable locally; SQLite is the tested persistence runtime.
